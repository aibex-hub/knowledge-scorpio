# knowledge-scorpio

Wissenspaket von AIbex AIOS, Version 0.1.0: Die 20 hellsten Sterne des Sternbilds Skorpion mit Helligkeit, Radius, Entfernung, Temperatur und Art. Die Tabelle liegt als verfügbares Wissen in `knowledge/@@Skorpion/Sterne.md` (Quelle: SIMBAD, ergänzt aus der englischen Wikipedia, abgerufen am 2026-10-21).

```bash
aios --fetch aibex-hub/knowledge-scorpio
```

Gedacht für den Demo-Assistenten Astronom (`assistent-astronom`), aber unabhängig von ihm.
